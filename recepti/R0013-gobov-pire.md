# Gobov pire

Temen, gladek pire iz dobro zapečenih šampinjonov, poglobljen z madeiro, šerijevim kisom in gobovo osnovo. V izvirniku je priloga k morskemu listu bonne femme.

**Izplen:** za dopolnitev.

## Sestavine

| Sestavina | Količina |
| --- | ---: |
| Rjavi šampinjoni, narezani | 750 g |
| Šalotki, narezani | 2 |
| Česen, nastrgan | 6 strokov |
| Maslo | 125 g |
| Madeira | 200 ml |
| Šerijev kis | 20 ml |
| [R0012 Gobova osnova](R0012-gobova-osnova.md) | 300 ml |
| Gosta smetana (double cream) | 150 ml |
| Mleko | 150 ml |
| Sol | ščep |

## Posebna oprema

Zmogljiv mešalnik in fino cedilo.

## Postopek

1. **Porjavi maslo.** V široki ponvi segrej maslo, da porjavi.
2. **Zapeci gobe.** Dodaj gobe in jih praži, da dobijo lepo barvo.
3. **Zmehčaj arome.** Dodaj šalotko, česen in ščep soli ter praži, da se zmehčajo.
4. **Deglaziraj po vrsti.** Najprej prilij kis, nato madeiro in nazadnje gobovo osnovo.
5. **Kuhaj s smetano.** Prilij smetano in mleko, da so gobe pokrite, in kuhaj **20 minut**.
6. **Spasiraj.** Pusti malo počivati, nato zmešaj do popolnoma gladke, povezane teksture.
7. **Precedi in poskusi.** Pretlači skozi fino cedilo ter uravnaj sol.
