# Spaghetti alla puttanesca

Paradižnikova omaka z inčuni, črnimi olivami, kaprami in čilijem.

## Sestavine

| Sestavina | Količina |
| --- | ---: |
| Špageti | 320 g |
| Pelati, ročno pretlačeni | 400 g |
| Črne olive, po možnosti Gaeta, grobo narezane | 80 g |
| Kapre, na hitro oplaknjene | 40 g |
| Fileji inčunov | 6–12 |
| Svež rdeči čili | 1 ali malo čilijevih kosmičev |
| Česen, nariban | 2 stroka |
| Oljčno olje | 4 žlice |
| Gladkolistni peteršilj | malo |
| Sol | samo po potrebi |
| Voda od kuhanja testenin | po potrebi |

## Postopek

1. **Pripravi osnovo.** V hladno ponev daj olje, česen, čili in inčune. Na srednjem ognju mešaj in stiskaj inčune, da razpadejo v olju. Česen naj ostane svetel.
2. **Pokuhaj paradižnik.** Dodaj pelate, zvišaj ogenj in odkrito kuhaj **5–7 minut**. Znižaj ogenj, dodaj olive in kapre ter kuhaj še **1–2 minuti**.
3. **Dokuhaj špagete.** Še čvrste špagete prestavi v omako. Prilij malo vode od kuhanja in dobro premešaj, da se omaka oprime testenin.
4. **Dokončaj.** Odstavi, dodaj malo sesekljanega peteršilja in po potrebi dosoli.

## Uredniška evidenca

- Količine in časi so iz avtorjevega pisnega recepta. Izplen je za dopolnitev.
