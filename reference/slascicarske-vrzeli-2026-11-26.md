# Slaščičarske vrzeli — viri in odločitve, 26. 11. 2026 (drugi sklop)

Uporabnik je vprašal, kaj od slaščičarskih stvari še manjka, in na seznam vrzeli odgovoril »vse dodaj!!«. Dodanih je 31 receptov R0195–R0225.

## Dostop
Okolju `cookbook` so dodani www.slovenian-kitchen.com, www.gov.si in www.visitljubljana.com (zadnji vrne 403). Chef Simon: strukturirani podatki in besedilo strani; pri strani Les Gourmets (drugi avtorji na chefsimon.com) so koraki pogosto skriti za oglasom (»Voir la recette«) in niso bili prebrani — tam so postopki uredniški in označeni. Wikibooks prek API z revizijami. Neodprti viri so kratko samostojno ubesedeni.
